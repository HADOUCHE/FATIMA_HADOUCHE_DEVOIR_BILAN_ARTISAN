                                                                           Trouve ton artisan
                                                                           
                                                                

Trouve ton artisan est une plateforme web permettant aux particuliers de rechercher des artisans dans la région Auvergne-Rhône-Alpes, de consulter leurs profils et de les contacter.

2. Technologies utilisées

  2.1 Frontend
      - React
      - Bootstrap
      - Sass
      - Vite

  2.2 Backend
      - Node.js
      - Express
      - Sequelize

  2.3 Base de données
      - MySQL / MariaDB

  2.4 Outils
    - Visual Studio Code
    - Figma
    - Git et GitHub

3. Installation

   3.1. Récupérer le projet

      3.1.1 Installer le frontend
             Dans un terminal :
     
                cd frontend
                npm install
                npm run dev

       3.1.2 Installer le backend

              Dans un autre terminal :
              
              cd backend
              npm install
              npm run dev
